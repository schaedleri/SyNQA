# SyNQA -- Synergistic Network QUBO Analysis

SyNQA formulates microbiome biomarker discovery as a quadratic
unconstrained binary optimization (QUBO) problem that jointly optimizes:

- **F**: standardized single-taxon effect size (Welch's t-statistic on
  CLR-transformed abundances between two disease groups)
- **J**: pairwise correlation divergence (Fisher z-transformed
  difference in Pearson correlation between the two groups)

Simulated annealing selects the taxon subset that minimizes the
resulting energy. Selection is validated through bootstrap resampling,
label-permutation testing, and knockout analysis.

The workflow has two stages: `synqa_pipeline.py` runs selection and
validation from raw data; `synqa_rescore.py` then re-ranks the
selected taxa and runs the cross-cohort meta-analysis on top of those
results, without re-running simulated annealing, bootstrap, or knockout
analysis.

## How it works

1. **Preprocessing**: raw counts are filtered by prevalence, CLR-transformed
   with a data-driven pseudo-count, and optionally adjusted for covariates
   (e.g. age, sex, BMI) via per-taxon OLS regression.
2. **F/J construction**: single-taxon effect sizes (F) and pairwise
   correlation divergence (J) are computed from the CLR-transformed data.
   Edge existence uses a fixed threshold (`|Z| >= edge_z_thresh`); the
   centering point used to drive the optimizer is determined by a
   data-driven Gaussian-mixture-model (GMM) procedure (Ashman's D
   separation statistic with a BIC gate), falling back to the empirical
   median when no statistically supported bimodal structure is present.
3. **Selection**: simulated annealing minimizes `E(s) = -F.s - s.J.s`
   over the binary selection vector `s`, run from multiple random seeds
   to check convergence.
4. **Validation**: bootstrap resampling estimates selection stability;
   label-permutation testing compares the observed number of edges,
   number of selected taxa (K) and cluster purity against label-shuffled
   nulls; knockout (KO) analysis measures each selected taxon's
   contribution to the optimized energy.
5. **Re-scoring & meta-analysis** (`synqa_rescore.py`, post-hoc): taxa
   are re-ranked by a composite `score_causal` (energy contribution x
   bootstrap frequency x sign consistency x stability), a GMM threshold
   splits each cohort's ranking into a high-importance tier, and cohorts
   are combined with a Stouffer meta-analysis. A fairness-check variant
   (`score_causal_strict`) tests whether taxa with no surviving network
   edge are getting an unearned advantage in the ranking.

Selection (F_energy/J_energy, centered) and interpretation are kept
separate throughout: every reported/interpreted quantity (taxon role,
network centrality, clustering) uses the original signed, degree-
normalized F/J values, not the centered energies used to drive the
optimizer.

## Requirements

```
numpy
pandas
scipy
scikit-learn
networkx
matplotlib
```

Install with:

```bash
pip install -r requirements.txt
```

(`synqa_rescore.py` uses the same dependencies -- no extra packages needed.)
`networkx` is optional for `synqa_pipeline.py`, but without it network
centrality and clustering are skipped.

## Input data

### Data availability

The datasets analyzed in the paper (WirbelJ 2019, ZellerG 2014, YachidaS 2019)
come from [curatedMetagenomicData](https://bioconductor.org/packages/curatedMetagenomicData/)
(Bioconductor) and are **not redistributed in this repository**; see
`data/raw/readme.txt`. To try the code right away, `data/demonstration/`
contains a small **synthetic** dataset (60 samples x 150 taxa, 3 mock cohorts)
generated by `data/demonstration/demodata.py`. Its abundances and labels are
random, so it only checks that the pipeline runs; the selected taxa carry no
biological meaning.

### Quick start with the demonstration data

```bash
python synqa_pipeline.py \
    --pooled_dir data/demonstration \
    --rank s \
    --regress_covariates age,BMI,sex \
    --n_seeds 5 --n_boot 20 \
    --out_dir demo_results/
```

Use `--rank s`: the demo taxa are species-level names only, so `g` and `f`
would just repeat the species table. The pooled files are split by study into
`demo_results/_pooled_cohorts/`; pass that directory as `--data_root` when
running `synqa_rescore.py` on these results.

### Your own data

SyNQA accepts either of two layouts.

**A. Pooled files (`--pooled_dir`)** -- the layout of `data/demonstration/`.
All tab-separated, first column = sample ID:

| File | Content |
|---|---|
| `X_all_raw.tsv` | samples x taxa relative abundances, header = taxon names (e.g. `s__Escherichia_coli`) |
| `y_all.tsv` | one column, `1` = disease (CRC), `0` = control |
| `study_id.tsv` | one column with the cohort/study name of each sample |
| `covariates.tsv` | *(optional)* `Age`, `Sex` (`Male`/`Female`), `BMI`; used by `--regress_covariates` |

Only samples present in `X_all_raw.tsv`, `y_all.tsv` and `study_id.tsv` are used.
Each study becomes one cohort.

**B. One pair of files per cohort (`--data_root`, or `SYNQA_DATA_ROOT`; default `./data`)**:
`meta_<name>.tsv` and `X_<name>.tsv`. Every such pair in the directory is picked
up automatically as cohort `<name>`; the three paper cohorts use these names
(the files you create from curatedMetagenomicData):

| Cohort name | Metadata file | Abundance file |
|---|---|---|
| `WirbelJ_2019` | `meta_WirbelJ_2019.tsv` | `X_WirbelJ_2019.tsv` |
| `Zeller_2014` | `meta_ZellerG_2014.tsv` | `X_ZellerG_2014.tsv` |
| `Yachida_2019` | `meta_YachidaS_2019.tsv` | `X_YachidaS_2019.tsv` |

- **Metadata** needs a sample ID column (`SampleID`, `sample_id`, or the first
  column) and a group column (`Group`, `disease`, `phenotype`, or
  `study_condition`). Values `CRC`, `crc`, `case`, `adenoma`, `Adenoma` are
  treated as the disease group; `Healthy`, `healthy`, `CTR`, `ctr`, `control`,
  `Control`, `normal` as the control group; other samples are dropped (label
  sets are defined in `load_data` in `synqa_pipeline.py`). Covariate columns
  for `--regress_covariates` (`age`, `BMI`, `sex`) are optional; common
  alternative column names are recognized.
- **Abundance table**: samples x taxa or taxa x samples (the orientation is
  detected automatically). If the taxon names are lineage strings with
  rank prefixes, as in the MetaPhlAn profiles of curatedMetagenomicData
  (`...|g__Escherichia|s__Escherichia_coli`), `--rank s/g/f` extracts the
  column of the chosen rank and sums duplicates. A table without such
  prefixes is used as-is for every rank.

## Usage

### Stage 1: selection and validation (`synqa_pipeline.py`)

```bash
python synqa_pipeline.py \
    --data_root /path/to/data \
    --regress_covariates age,BMI,sex \
    --cohort all --rank all \
    --run_ko --run_perm \
    --n_seeds 30 --n_boot 1000 --n_perm 2000 \
    --centering_mode gmm --center_source resample \
    --out_dir results/
```

### Stage 2: re-scoring and meta-analysis (`synqa_rescore.py`)

Run on the `results/` directory produced by stage 1:

```bash
python synqa_rescore.py \
    --results_dir results/ \
    --out_dir results/ \
    --data_root /path/to/data \
    --regress_covariates age,BMI,sex \
    --top_n 10 --min_boot_prob 0.5 --min_stability_cross 0.5
```

This does not re-run simulated annealing, bootstrap, or KO -- it reads
`taxa_{tag}.tsv`, `summary_{tag}.tsv` and `all_permtest.tsv` from
`--results_dir` and writes its own re-ranked/meta-analysis tables
alongside them (see Output below). Use `--skip_rescore` or `--skip_meta`
to run only one of the two steps.

`--data_root` and `--regress_covariates` are only used to recover the
pre/post-filter taxa counts and full-network edge counts for
`filter_and_selection_summary.tsv` (this needs `synqa_pipeline.py` in the
same directory). Pass the same values as in stage 1; if the data or
module cannot be found, those columns are filled with `n/a`.

For a sample-size-weighted meta-analysis, give the cohort sizes:

```bash
python synqa_rescore.py --results_dir results/ --weight_by_n \
    --n_map WirbelJ_2019=125,Zeller_2014=114,Yachida_2019=571
```

### Key arguments

**`synqa_pipeline.py`**

| Argument | Description |
|---|---|
| `--data_root` | Directory with the cohort input files (default: `$SYNQA_DATA_ROOT` or `./data`) |
| `--pooled_dir` | Use a pooled dataset (`X_all_raw.tsv`, `y_all.tsv`, `study_id.tsv`, optional `covariates.tsv`; see `data/demonstration`) instead of `--data_root`. It is split by study into `<out_dir>/_pooled_cohorts` |
| `--cohort` | Cohort name, or `all` for every cohort found |
| `--rank` | Taxonomic rank to run: `s`, `g`, `f` or `all` |
| `--n_seeds` | Number of simulated-annealing random seeds (for convergence assessment) |
| `--n_boot` | Number of bootstrap resamples (`0` skips bootstrap for a lightweight run) |
| `--run_ko` | Run knockout analysis on the selected taxa |
| `--run_perm` | Run label-permutation testing (`--n_perm`, `--perm_n_seeds`) |
| `--regress_covariates` | Comma-separated covariates to regress out of CLR values (e.g. `age,BMI,sex`) |
| `--centering_mode` | `median` (default) or `gmm` (data-driven, falls back to median) |
| `--center_source` | `resample` (recompute the centering point per bootstrap/permutation draw) or `observed` (freeze it at the value computed from the real-label full dataset) |
| `--ashman_d_threshold` | Minimum Ashman's D for the GMM crossing point to be used instead of the median fallback |
| `--edge_z_thresh` | Minimum `|Z|` for a taxon pair to be considered an edge (default 1.96) |
| `--min_prev`, `--group_mode`, `--min_info_prev`, `--noise_floor_pct`, `--info_combine` | Prevalence/noise-floor filtering parameters |
| `--out_dir` | Output directory (default `synqa_results`) |

Run `python synqa_pipeline.py --help` for the full list.

**`synqa_rescore.py`**

| Argument | Description |
|---|---|
| `--results_dir` | Directory containing `synqa_pipeline.py`'s output (default `synqa_results`) |
| `--out_dir` | Where to write outputs (default: same as `--results_dir`) |
| `--data_root` | Raw data directory, only used to recover filter/edge counts (default: `$SYNQA_DATA_ROOT` or `./data`) |
| `--regress_covariates` | Same value as used in stage 1, so recovered edge counts match |
| `--top_n` | How many top taxa to print per tag |
| `--min_boot_prob` | Only print taxa with `boot_prob >=` this in the per-tag rescore tables |
| `--min_stability_cross` | Stability threshold for the cross-cohort stable-taxa summary |
| `--weight_by_n` | Weight each cohort's z-score by `sqrt(sample size)` instead of equal weighting (meta-analysis only) |
| `--n_map` | Cohort sample sizes for `--weight_by_n`, e.g. `A=125,B=114` |
| `--skip_rescore` | Skip the re-ranking step, only run the meta-analysis |
| `--skip_meta` | Skip the meta-analysis step, only run the re-ranking |

Run `python synqa_rescore.py --help` for the full list.

## Output

For each cohort/rank combination (tagged `{cohort}_{rank}`), `synqa_pipeline.py`
writes to `--out_dir`:

- `taxa_{tag}.tsv` -- selected taxa with effect sizes, bootstrap
  probability, stability, network role, and cluster assignment
- `summary_{tag}.tsv` -- landscape summary (K, convergence diagnostics,
  GMM centering diagnostics, Ashman's D, BIC gap)
- `rank_{tag}_Dual.tsv` -- taxa ranked by causal importance score
- `ko_{tag}_Dual.tsv` -- knockout analysis results (if `--run_ko`)
- `permtest_{tag}.tsv` -- permutation-test results (if `--run_perm`)

Combined across all cohorts/ranks run in one invocation:

- `all_taxa.tsv`, `all_ranked.tsv`, `all_permtest.tsv`
- `gmm_centering_bic_diagnostics.tsv` -- GMM threshold diagnostics
  (method used, Ashman's D, BIC gap) for every cohort/rank pattern

`synqa_rescore.py` then adds, per cohort/rank tag:

- `rank_{tag}_Dual_rescored.tsv` -- taxa re-ranked by `score_causal`,
  with the GMM high-importance flag
- `bias_check_{tag}.tsv` -- per-taxon F/J score fairness check
  (`score_causal` vs the `score_causal_strict` sensitivity variant)
- `gmm_plots/gmm_threshold_{tag}.jpg` -- histogram of the K=2 GMM fit
  used to set the high-importance threshold

And combined across all tags:

- `all_ranked_rescored.tsv` -- combined re-ranked table
- `bias_check_summary.tsv` -- fairness-check summary across patterns
- `gmm_plots/gmm_threshold_ALL_PATTERNS.jpg` -- combined GMM overview
- `tail_vs_top_networkness.tsv`, `turnover_top_vs_tail.tsv`,
  `top_vs_tail_summary.tsv` -- top-tier vs. tail comparisons (network
  dominance, cross-cohort reproducibility)
- `filter_and_selection_summary.tsv` -- filtering/selection stats per tag
- `cross_cohort_{rank}_rescored.tsv`, `confirmed_candidates_{rank}.tsv` --
  taxa stable across all cohorts, and the strict cross-cohort-stable +
  GMM-high-importance-in-every-cohort subset
- `permutation_test_summary.tsv`, `meta_analysis_summary.tsv` -- the
  reformatted permutation-test table and the Stouffer meta-analysis
  across cohorts

The cross-cohort files are only written when more than one cohort was run.
